# Klarweg — German B1

A polished, responsive PWA prototype built from the supplied German B1 product brief and thematic vocabulary collection.

## Run locally

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Included

- Responsive dashboard, interactive lesson, vocabulary explorer, speaking lab, AI tutor mock and progress analytics
- All 808 vocabulary items across 16 themes and units E25–E34
- Search, article/category/unit filters, pronunciation via browser speech synthesis and flashcard sprint
- Interactive sentence builder, daily challenge, dark mode, keyboard shortcuts and command palette
- Installable PWA shell with offline caching
- Accessibility details including semantic structure, visible focus states, keyboard interaction and reduced-motion support

The AI, speech assessment, authentication and cloud synchronization are represented as production-quality front-end interactions; connecting live services would be the next implementation step.
